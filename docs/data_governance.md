# Data Governance and Privacy

- Do not commit patient-identifiable images, medical records, or private metadata.
- Do not add credentials, API keys, access tokens, or private filesystem paths to notebooks.
- Confirm dataset licensing and redistribution permission before sharing data.
- Keep large MRI datasets and model weights out of Git unless permission and storage requirements are explicitly satisfied.
- Use de-identified, authorized data for demonstrations and testing.
- Treat model outputs as research outputs, not medical advice or a diagnosis.
