# Release Checklist

- [ ] Confirm dataset and model redistribution permissions.
- [ ] Review notebook outputs for credentials, personal paths, and sensitive information.
- [ ] Confirm `.gitignore` excludes datasets and large model files.
- [ ] Install dependencies in a clean environment.
- [ ] Run repository validation and unit tests.
- [ ] Train or provide the authorized model artifact locally.
- [ ] Test all four class labels in the application.
- [ ] Test Grad-CAM rendering.
- [ ] Test PDF report generation.
- [ ] Verify that the README metrics are labelled as validation metrics.
- [ ] Verify medical safety and intended-use disclaimers.
- [ ] Review the final Git diff before publishing.
