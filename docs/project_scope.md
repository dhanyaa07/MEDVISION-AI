# MEDVISION AI - Project Scope

## Objective
Develop an AI-based brain MRI image classification research prototype using deep learning.

## Classification Categories
- Glioma
- Meningioma
- No Tumor
- Pituitary

## Core Features
- MRI image classification
- EfficientNetB0 transfer learning
- Grad-CAM explainability
- Image quality analysis
- Medical information report generation
- PDF report generation
- Gradio-based user interface

## Intended Use
This project is developed for academic and research purposes. It is not a clinically validated diagnostic system.

## Technology Stack
Python, TensorFlow, Keras, EfficientNetB0, OpenCV, Grad-CAM, Gradio and ReportLab.
