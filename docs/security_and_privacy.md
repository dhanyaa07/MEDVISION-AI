# Security and Privacy Notes

- Treat uploaded MRI images as sensitive data.
- Prefer local execution for private or identifiable images.
- Do not enable public share links by default.
- Do not store uploaded images longer than required for the demonstration.
- Do not add credentials or private tokens to source code or notebooks.
- Review generated reports before sharing; they may contain user-supplied images and model outputs.
- This project is not a clinical system and has no established clinical data-security certification.
